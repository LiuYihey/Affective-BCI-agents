# Playbooks

Checklists for the three situations where you need to decide whether a piece of
affective BCI work holds up. Each one is short enough to run against a
manuscript, a proposal, or your own plan.

- **[Designing an evaluation](evaluation-protocol.md)** — before you report a
  number, decide what the number answers.
- **[Designing a closed loop](closed-loop-design.md)** — before you let a
  decoder act, decide what happens when it is wrong.
- **[Reviewing a pilot system](maturity-ladder.md)** — before you call something
  a system, decide which level it has reached.

Each playbook names the failure it prevents, and links to the references that
documented it.
